# Customer Churn Analysis (Power BI)

An end-to-end Power BI report examining telecom customer churn patterns, high-risk customer segments, and retention opportunities.

## Report Structure & Pages
- **Overview & Problem Framing:** Title, About, Business Problem, Problem Statement, Objective, Introduction, and Column Overview
- **Customer Demographics Analysis:** Guided analysis questions and demographic breakdowns
- **Service Subscription Analysis:** Guided analysis questions and add-on/service usage patterns
- **Contract & Billing Insights:** Guided analysis questions and contract/billing behavior
- **Churn Prediction & Key Drivers:** Guided analysis questions and primary factors linked to churn
- **Wrap-Up:** Key Insights, Recommendations, Conclusion, and Q&A

3. Navigate across report pages or use filters/slicers to explore segments.
